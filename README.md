# 黑利群的博客

基于 [Mizuki](https://github.com/LyraVoid/Mizuki)（[Fuwari](https://github.com/saicaca/fuwari)）主题搭建的个人博客，记录学习、折腾、创作和生活碎片。

**线上地址**：https://mizuki-master-two.vercel.app

## 技术栈

Astro 6 + Svelte 5 + TypeScript + Tailwind CSS 4，部署在 Vercel。

## 本地开发

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm build      # 生产构建
```
